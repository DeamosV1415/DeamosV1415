### 📱 GitNomad
**Mobile Git Editor + VS Code Extension**

> *Code from your pocket — your desktop does the heavy lifting.*

Your phone edits. Your desktop commits. Your repo stays the source of truth.

```
Phone edit  →  VS Code commit  (live)
Phone cmd   →  Desktop runs it  →  Output streams back
Unsaved draft on desktop  →  Appears on phone
```

- 🔄 **Two-way real-time sync** — even unsaved drafts
- 🖥️ Run any **terminal command** from your phone
- 🛡️ Safe conflict resolution via per-hunk phone review
- 🐚 Supports PowerShell · cmd · bash · WSL · Git Bash
- 📦 Published on **VS Code Marketplace** & **Google Play**
